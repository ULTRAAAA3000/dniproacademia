# Дніпро Академія

Електронний щоденник та сайт гімназії. Проєкт перенесено з WordPress (плагін «Щоденник» та сторінка в Elementor) на Cloudflare Pages + база D1. Весь код написано на TypeScript.

- Керівник проєкту: (ПІБ, посада — вказати перед здачею)
- Консультант: (за потреби)

## 2. Тема, анотація, мова

Тема: веб-платформа електронного щоденника для гімназії.

Що вміє:

- головна сторінка закладу;
- реєстрація, вхід із кодом на пошту (2FA), відновлення пароля за кодовим словом;
- кабінет учня: новини, розклад, завдання, оцінки, середній бал, матеріали;
- кабінет вчителя: завдання, оцінки, підсумкові оцінки, новини, матеріали, експорт оцінок у Excel;
- чат між користувачами (файли, відповіді, редагування, блокування);
- панель адміністратора: користувачі, класи, розклад, налаштування, безпека, журнал дій.

Мова: TypeScript 5. Сервер працює в Cloudflare Workers (Pages Functions), база — Cloudflare D1 (SQLite), файли — Cloudflare R2. Збірка: Node.js 20+, esbuild.

## 3. Вимоги до апаратури

Для користувача: будь-який комп'ютер або телефон із сучасним браузером. Додаткових пристроїв не потрібно.

Для розробки: двоядерний процесор, 4 ГБ оперативної пам'яті, приблизно 600 МБ на диску (разом із `node_modules`). Сам проєкт без залежностей займає близько 3 МБ, із них 1 МБ — шрифти.

## 4. Вимоги до системи

Windows 10/11, Linux або macOS. Для запуску на своєму комп'ютері потрібен лише Node.js (версія 20 або новіша) та інтернет для встановлення пакетів. Додаткових системних бібліотек не потрібно.

## 5. Програмне забезпечення на демонстраційному комп'ютері

- браузер Chrome, Edge або Firefox (актуальна версія);
- для запуску локально: Node.js 20+ та Git;
- для публікації: безкоштовний акаунт Cloudflare та акаунт GitHub.

## 6. Файл запуску

Окремого exe немає. Сайт відкривається за адресою, яку дає Cloudflare Pages. Локально:

```
npm install
npm run dev
```

Після цього сайт буде на `http://localhost:8788`. Точка входу сервера — `functions/[[path]].ts`, головна сторінка — `public/index.html`.

## 7. Установка та особливості роботи

### Структура

```
public/            готові файли сайту (index.html, стилі, шрифти, зображення)
src/client/        скрипти для браузера (TypeScript → public/assets)
src/server/        серверний код (API, сторінки кабінету та адмінки, база)
functions/         вхід для Cloudflare Pages Functions
migrations/        схема бази D1
wrangler.toml      налаштування Cloudflare
```

### Публікація на Cloudflare

1. Створити базу D1: `npx wrangler d1 create dniproacademia`. Id бази вписати в `wrangler.toml` у `database_id`.
2. Створити сховище R2: `npx wrangler r2 bucket create dniproacademia-files`.
3. Створити таблиці: `npm run db:init:remote`.
4. У Cloudflare: Workers & Pages → Create → Pages → Connect to Git → вибрати цей репозиторій.
   Build command: `npm run build`, Build output directory: `public`.
5. У Settings → Variables and Secrets додати змінні (див. нижче).
6. Покласти в `public/images` три зображення новин: `Win.png`, `OpenDoor.png`, `Chat.png`.

### Змінні

| Змінна | Для чого |
|---|---|
| `ADMIN_PASSWORD` | пароль входу в `/admin` |
| `ADMIN_EMAIL` | куди надсилати сповіщення про підозрілі входи |
| `MAIL_FROM` | адреса відправника листів (домен має бути підключений до Cloudflare Email Service) |
| `CF_ACCOUNT_ID` | id акаунта Cloudflare |
| `CF_EMAIL_TOKEN` | API-токен з правом відправляти пошту |
| `MAIL_DEBUG` | `1` — не слати листи, а писати їх у лог (тільки для перевірки) |

Листи (код входу, підтвердження пошти) відправляються через Cloudflare Email Service. Для відправки довільним адресатам потрібен платний план Workers.

### Особливості

- Адреси кабінету залишились ті самі: `/da-login` та `/da-cabinet`. Адмінка: `/admin`.
- Старі файли та повідомлення чату очищаються автоматично раз на добу (при першому заході в кабінет). Налаштування — у вкладці «Налаштування» адмінки.
- Автоматичне опитування чату зупиняється, коли вкладка неактивна, щоб не витрачати ліміти безкоштовного плану.
- Пароль адміністратора не зберігається в базі, лише в змінних Cloudflare.
